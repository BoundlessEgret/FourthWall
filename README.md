# 第四面牆 FourthWall ～ Behind the Bullet Curtain

東方 Project 風格的 2D 彈幕射擊遊戲。全員原創角色，所有圖像都是向量即時繪製（非像素畫），所有音樂與音效都由 WebAudio 即時合成，沒有任何外部素材。

## 怎麼玩

直接用瀏覽器開啟 `index.html` 即可（Chrome / Edge / Firefox 建議）。不需要安裝、不需要伺服器。

| 按鍵 | 功能 |
|---|---|
| 方向鍵 / WASD | 移動 |
| Z | 射擊 / 決定 |
| X | 符卡（炸彈）/ 取消 |
| Shift | 低速移動（顯示判定點） |
| Esc | 暫停 |
| Ctrl | 快轉對話 |

也支援手把（A 射擊、B 符卡、LB/RB 低速、Start 暫停）。

被擊中後的短暫時間內按 X 可以「決死」回避。

### 手機（觸控）

第一次觸碰螢幕就會自動切換成觸控操作：

- **在畫面任意處拖曳**＝移動自機（相對移動，手指不會擋住自機），**自動射擊**
- 左下：**符卡**、**低速**（切換）　右下：**快轉**對話、**暫停**
- 選單：直接點選項目（點一次選取、再點一次決定），或用虛擬方向鍵＋決定／返回
- **橫向**握持畫面最大；**直向**時遊戲中會自動只顯示遊戲區＋精簡 HUD，下方空白處就是拖曳區
- 右上角 ⛶ 可切換全螢幕

手機要能開啟這個資料夾，最簡單的方式是在電腦上執行 `python3 -m http.server 8000`，再用同一個 Wi-Fi 下的手機瀏覽器開 `http://<電腦的區網IP>:8000`。

## 內容

- **6 位可操作角色**（全部原創）：玲音、千代、茜、汐、棗、鈴，各自有不同的射擊方式與符卡。
- **另外 2 位頭目**：無名（被刪除的角色）、幕（第四面牆本人）。
- **劇情模式**：6 關，每關都有道中、中頭目、頭目戰與對話。對手與對話會依你選的角色變化（每個組合都有專屬台詞）。
- **Extra 關卡**：通關後解鎖，真・最終頭目與真結局。
- **無盡幕間 ∞**：沒有結尾的模式。難度會逐漸提高，但有**固定上限**；每擊敗一位頭目都會掉落殘機／符卡補給，所以只要你有時間、有操作，就能一直玩下去。
- **結局 8 種**：6 個角色 Good Ending、Bad Ending（接關通關）、True Ending。
- **幕間劇場「F W」**：Galgame（視覺小說）格式的短篇，有選項分歧、好感度、AUTO／SKIP／LOG。關於 FourthWall 的縮寫 FW 在簡中網路上的另一個意思……（標題畫面打 F、W 也能進入）
- **符卡練習**、**角色圖鑑**（可以戳角色）、**音樂室**（21 首原創曲）、**紀錄與成就**（21 個成就）、**設定**。
- 難度：Easy / Normal / Hard。另有「自動符卡」輔助選項。

## 打破第四面牆

每位角色的符卡演出都會打破第四面牆：

| 角色 | 符卡 | 演出 |
|---|---|---|
| 玲音 | 暫停．非暫停 | 叫出假的暫停選單，從裡面走出來，選擇一個「隱藏選項」 |
| 千代 | ※此對話無法跳過 | 巨大對話框；你按 Z 或 Ctrl 想跳過，她會生氣 |
| 茜 | 致命錯誤 | 假當機（分頁標題變成「沒有回應」）→ 藍色畫面 → 從裡面一拳打碎螢幕 |
| 汐 | 借我一下你的滑鼠 | 徵用你的滑鼠游標，框選所有子彈，右鍵「刪除」 |
| 棗 | 片尾名單（提前播放） | 提前播放片尾名單，每一行字都是一道牆 |
| 鈴 | 越界 | 抓住遊戲畫面的邊框往外拉，把分數欄擠扁，再敲敲螢幕 |

其他還有：角色會記得你上次什麼時候來、玩了多久、倒下幾次；在深夜遊玩會被關心；切換分頁再回來會被問「你剛剛去哪了？」；頭目會讀取現在的真實時間、你的分數欄、你的存檔……

> 這些全部都只是演出，不會對電腦做任何事。分頁標題特效可在設定中關閉。存檔存在瀏覽器的 localStorage。

## 檔案結構

```
index.html        進入點
js/core.js        數學、輸入、存檔、協程
js/audio.js       合成器、音序器、全部樂曲與音效
js/art.js         向量角色繪製（立繪＋Q版）
js/chars.js       角色資料
js/sprites.js     子彈、道具
js/bg.js          關卡背景
js/game.js        遊戲本體（自機、敵人、碰撞、繪製）
js/boss.js        頭目、對話、HUD、流程
js/bosses.js      所有彈幕與符卡
js/stages.js      關卡與無盡模式
js/story.js       劇本、結局
js/bombs.js       六種第四面牆符卡
js/scenes.js      標題、選單、結局、名單等畫面
js/touch.js       手機觸控操作
js/galgame.js     視覺小說引擎＋幕間劇場
js/main.js        主迴圈
```
